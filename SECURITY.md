# Security policy

Please report vulnerabilities privately through GitHub Security Advisories rather than a
public issue. Include the affected commit, a minimal reproduction, and the expected
fail-closed behavior.

This project protects an agent or workspace from untrusted content entering model context
or being adopted without review. It does not claim to contain a fully compromised host.
Docker is defense in depth, not a kernel-strength security boundary. A scan result of
NO_FINDINGS is not a guarantee that an artifact is safe.
